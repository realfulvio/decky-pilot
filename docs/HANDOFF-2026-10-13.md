## Decisioni e limiti reali

**Cattura automatica e diretta di produzione ancora DISABILITATE**;
`CAPTURE_SAFETY_VALIDATED=False`. Non basta impostare questo flag a True per completare il lavoro.
Il protocollo Gamescope esaminato riceve percorso/tipo/flag dello screenshot, senza identificatore
atomico della superficie bersaglio. Controllare focus/AppID prima e dopo non prova la provenienza
dei pixel nel mezzo. Il prossimo intervento deve risolvere questo limite, non aggiungere altri
controlli del titolo o una cattura generica del desktop.

È un rafforzamento difensivo: la cache incoerente è stata iniettata dai test, non è stata
osservata una cattura privata né dimostrato un attacco tramite RPC. È stato invece verificato
nel codice e nei test che il precedente ordine arrivava alla gestione credenziali prima del
rifiuto della cattura. Ora il rifiuto precede anche questi effetti esterni.

Nessuna modifica a provider, UI, import manuale, conversazione, popup di 6 secondi, voce,
spoiler o impostazioni salvate. Nome pubblico Decky Pilot; identificatori interni conservati.
Nessuna dipendenza nuova, servizio o configurazione di sistema. Nessun account AI reale,
richiesta a pagamento, installazione su Deck, merge, force push, release o store.

## Ripresa dal PC di casa

Prerequisiti: Git con accesso al repository; Node nel range del package, preferibilmente
24.20.0; Corepack/pnpm 10.28.2; Python compatibile e dipendenze in un nuovo venv. Per Linux
usare una VM disponibile, senza condividere credenziali. Non servono account AI per i test.

Nuovo clone, da una directory a scelta:

```powershell
$target = Join-Path (Get-Location) 'decky-pilot-safe-capture-20261013'
if (Test-Path -LiteralPath $target) { throw 'Destinazione esistente: non sovrascrivo.' }
git clone --branch codex/decky-pilot-safe-capture-20261013 --single-branch https://github.com/realfulvio/decky-pilot.git $target
if ($LASTEXITCODE -ne 0) { throw 'Clone fallito.' }
Set-Location -LiteralPath $target
git status --short --branch
git log -1 --oneline
```

Checkout esistente: eseguire dalla sua radice; il blocco si ferma prima di cambiare branch
se trova modifiche tracciate/non tracciate oppure un branch locale già presente.

```powershell
$branch = 'codex/decky-pilot-safe-capture-20261013'
git rev-parse --show-toplevel
if ($LASTEXITCODE -ne 0) { throw 'Non sei in un repository Git.' }
$dirty = @(git status --porcelain)
if ($LASTEXITCODE -ne 0 -or $dirty.Count -gt 0) { throw 'Checkout non pulito: salva e controlla il lavoro locale prima di proseguire.' }
$origin = git remote get-url origin
if ($origin -notmatch 'github\.com[:/]realfulvio/decky-pilot(?:\.git)?$') { throw 'Origin diverso dal repository previsto.' }
git fetch origin "refs/heads/${branch}:refs/remotes/origin/${branch}"
if ($LASTEXITCODE -ne 0) { throw 'Fetch fallito.' }
git show-ref --verify --quiet "refs/heads/$branch"
if ($LASTEXITCODE -eq 0) { throw 'Branch locale già presente: confrontalo con origin prima di cambiarlo o aggiornarlo.' }
git switch --create $branch --track "origin/$branch"
if ($LASTEXITCODE -ne 0) { throw 'Cambio branch fallito; controlla i file locali.' }
git status --short --branch
git log -1 --oneline
```
