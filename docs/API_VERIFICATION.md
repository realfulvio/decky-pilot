## Provider e voce

Ogni provider ha `validate_config`, `capabilities`, `generate`. Trasporto stdlib TLS verificato, connect/TLS ~5 s, deadline cloud 45 s, Ollama 45–120 s; JSON massimo 2 MB/audio 8 MB. Gli errori non includono body/header remoti. Niente streaming o retry di generazioni; nessun fallback tra destinatari. Lo schema supporto immagini cloud è una conferma esplicita dell'utente per il modello scelto, **non** una capacità verificata dall'account. Ollama usa anche `/api/show` prima dell'invio immagine.
